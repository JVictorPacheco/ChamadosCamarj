# Glossário

Termos usados no portal e nesta documentação, em ordem alfabética.

| Termo | Significado |
|---|---|
| **Admin** | Perfil com controle total do sistema. Ver [[Perfis e Permissões]]. |
| **Anexo** | Arquivo (PDF, imagem, Office, ZIP — até 10 MB) ligado a um chamado ou comentário. Ver [[Anexos]]. |
| **Arquivo de Chamados** | Tela de consulta dos chamados finalizados. Não confundir com *anexo*. Ver [[Arquivo de Chamados]]. |
| **Assumir** | Ação do atendente de tomar um chamado para si; o chamado passa a *Em andamento*. |
| **Atendente** | Perfil de quem trata chamados. |
| **Cancelado** | Chamado interrompido antes de ser resolvido, sempre com um motivo. |
| **Área** | De onde o chamado é aberto. É a mesma lista das equipes (ex.: Reembolso, Financeiro). |
| **Tipo** | Natureza do pedido: Incidente, Dúvida, Solicitação, Customização ou Melhoria. |
| **Categoria** | *(nome antigo)* Substituída por Área + Tipo em 2026-10. |
| **Chamado** | Registro formal de uma solicitação, identificado por um número `CAM-N`. |
| **ChatPerfil** | Nível de acesso de uma pessoa ao chat: *Sem acesso*, *Participante* ou *Criador de grupo*. Definido pelo Admin. |
| **Comentário interno** | Comentário visível só para Atendentes e Admin — o solicitante não vê. |
| **Comentário público** | Comentário visível para todos os envolvidos no chamado. |
| **Dashboard** | Painel com números em tempo real ("foto do momento"). Diferente do *Relatório Mensal*. |
| **Em andamento** | Chamado que já tem um responsável trabalhando nele. |
| **Encerramento forçado** | Ação exclusiva do Admin de fechar um chamado em qualquer etapa, com motivo. Ver [[Encerramento e Cancelamento]]. |
| **Equipe / Grupo** | Conjunto de pessoas de um mesmo setor. Atendentes veem os chamados da sua equipe. Ver [[Grupos e Equipes]]. |
| **Fechado (Encerrado)** | Etapa final: o chamado resolvido foi confirmado e encerrado. |
| **Fila** | Lista dos chamados *Abertos*, ordenada por prioridade, aguardando alguém assumir. |
| **Histórico** | Registro automático de cada ação feita no chamado: quem, o quê e quando. |
| **Kanban** | Quadro com uma coluna por status; os chamados são arrastados entre colunas. |
| **Motivo de encerramento** | Razão registrada ao fechar ou cancelar: Resolvido, Cancelado pelo solicitante, Aberto indevidamente, Duplicata, Sem resposta ou Outro. |
| **Número do chamado** | Identificador amigável `CAM-{número}`, sequencial, usado em conversas e e-mails. |
| **Prioridade** | Urgência do chamado: Baixa, Média, Alta ou Urgente. Define o prazo (SLA). |
| **Reabrir** | Voltar um chamado finalizado para *Aberto*; o responsável é removido. |
| **Reatribuir** | Ação do Admin de trocar o responsável por um chamado. |
| **Relatório Mensal** | Documento de um mês fechado, para prestação de contas. Ver [[Relatório Mensal]]. |
| **Resolvido** | O atendente concluiu o trabalho; aguarda o encerramento. **Não é o mesmo que Fechado.** |
| **SLA** | *Service Level Agreement* — prazo máximo para resolver o chamado, conforme a prioridade. Ver [[SLA]]. |
| **Solicitante** | Quem abre o chamado. |
| **Triagem automática** | Sugestão de área e tipo feita pelo sistema a partir das palavras do chamado. |
